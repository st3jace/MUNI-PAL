# sourcing/ — where names come from (no EMMA)

Target: 100 obligated persons who have already issued conduit debt and still have live continuing-disclosure duties.

Sources, in order of yield:
1. IDA / authority board agendas and minutes. Every approved conduit deal names the borrower. Public record.
2. State bond-authority annual reports (housing finance agencies, health/ed facilities authorities).
3. County recorder filings (deeds of trust naming the trustee and borrower).
4. Clay (workspace "ELaunch Shop") to find the CFO / controller once the company is known.

Each row must record its `source` as one of the above. `emma-operator` rows are being re-found here so the column is clean.
